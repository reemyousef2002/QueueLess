# QueueLess

QueueLess turns physical lines at clinics, bakeries, water points, community
kitchens, university offices, and government offices into a live ticket you
can track from anywhere — so you only show up when it's actually your turn.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — build for production
- `npm run preview` — preview the production build locally
- `npm run lint` — run eslint
- `npm run format` — run prettier
